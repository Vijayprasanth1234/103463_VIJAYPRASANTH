# Project Documentation

Welcome to the project documentation!

## Overview

This project provides a simple structure for starting a new Python project. The repository structure is created using the `setup.sh` script.

## Getting Started

To set up the repository structure, run:

```bash
./setup.sh
```

This will create all necessary files and folders for the project.

## Project Structure

- `src/`: Source code
- `tests/`: Unit tests
- `docs/`: Documentation
- `config/`: Configuration files

For more information, see the [usage guide](usage.md).
